# CGV 좌석 감시 도구

CGV 예매 페이지의 **새로고침 버튼을 대신 눌러주고**, 원하는 조건의 빈자리가 나오면
텔레그램으로 알려주는 도구입니다. 허리 때문에 오래 앉아 새로고침을 반복하기 어려운 상황을
위해 만들었습니다.

### 웹모드 자동 진행 (선택 기능)

타겟 좌석 발견 시:
인원 선택 → 좌석 클릭 → 선택완료 → 결제하기 화면까지 자동 이동.
**결제 정보 입력·최종 결제는 사람이 직접** 합니다.
외출모드에서는 알림만 보냅니다.

## 동작 방식

브라우저가 새로고침할 때 페이지가 **스스로 보내는 좌석 조회 응답을 가로채서** 읽습니다.
스크립트가 API를 직접 호출하지 않으므로(직접 호출은 403으로 막힙니다) 사람이 새로고침을
누르는 것과 트래픽이 동일합니다.

## 준비물

- Python 3 + `selenium`
- Microsoft Edge, 그리고 설치된 Edge 버전에 맞는 `msedgedriver.exe` → `driver/` 에 배치
- 텔레그램 봇 (알림용)

```bash
pip install selenium
```

## 설정

1. 텔레그램에서 `@BotFather`(파란 인증 배지 확인)에게 `/newbot` → 토큰 받기
2. 만들어진 봇에게 아무 메시지나 한 번 보내기
3. `run_cgv.bat.example` 을 `run_cgv.bat` 으로 복사하고 토큰 입력
4. 실행 후 **텔레그램 chat_id 찾기** 버튼 → 나온 값을 `run_cgv.bat` 에 입력
5. **폰 알림 테스트** 로 확인

```bash
run_cgv.bat
```

## 사용

```
로그인 준비  →  예매창 이동  →  (모드 선택)  →  빈자리 감시 시작
```

로그인은 최초 1회만 하면 세션이 저장되어 다음 실행부터 생략됩니다.

### 모드

| | 웹모드 (PC 앞) | 외출모드 |
|---|---|---|
| 발견 시 | 감시 중지 → 인원 선택 → 좌석 화면까지 열어둠 | 화면 안 건드림 |
| 팝업 | 1회 | 없음 |
| 텔레그램 | 1회 | 매 체크마다 반복 |

어느 모드든 **좌석 클릭과 결제는 사람이 직접** 합니다.

### 폰에서 쓰는 원격 명령

| 명령 | 설명 |
|---|---|
| `/status` | 상태, 모드, 주기, 최근 로그 |
| `/watch` `/stop` | 감시 시작 / 중지 |
| `/log` | 최근 로그 20줄 |
| `/shot` | 현재 브라우저 화면 사진 |
| `/interval 5` | 감시 주기(초) 변경 |
| `/mode away\|web` | 모드 전환 |

본인 `chat_id` 에서 온 명령만 처리합니다.

## 감시 조건

`cgv_gui.py` 상단에서 바꿉니다.

```python
MOVIE_ALT = "오디세이 포스터"
SITE_NAME = "용산아이파크몰"
DAY_NUMBER = "31"
SHOW_TIME  = "07:30"
PEOPLE_COUNT = 2

EXCLUDE_ZONES = {"Light존"}          # 스크린 바로 앞줄 (휠체어 전용석 포함)
TARGET_ROWS   = {"E","F","G","H","I","J","K","L"}
SEAT_NO_MIN, SEAT_NO_MAX = 8, 37
REQUIRE_PAIR  = True                 # 붙어있는 2연석일 때만 알림
```
